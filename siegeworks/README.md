# Siegeworks

A voxel diorama of a medieval capital under siege, in a single HTML file. Play it at https://play-grounds.github.io/games/siegeworks/

- The prompt that produced the game is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; everything else is generated procedurally in the browser.
