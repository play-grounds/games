# Ant Kingdom

A voxel ant colony in a glass ant farm, in a single HTML file. Play it at https://play-grounds.github.io/games/antkingdom/

- The brief that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; the soil, the colony and its behaviour are all generated and simulated in the browser.
