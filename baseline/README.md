# Baseline

A playable voxel women's tennis game, in a single HTML file. Play it at https://play-grounds.github.io/games/baseline/

- The brief that produced the game is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; the stadium, the players, the ball physics and the umpire's voice (the browser's own speech synthesis) are all generated in the browser. The players and tournament are fictional.
