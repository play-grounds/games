# Bottleship

A voxel galleon sails a living ocean sealed inside a glass bottle, in a single HTML file. Play it at https://play-grounds.github.io/games/bottleship/

- The prompt that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; everything else is generated procedurally in the browser.
