# Clockwork Orrery

A brass orrery under a glass dome in a study at night, in a single HTML file. Play it at https://play-grounds.github.io/games/orrery/

- The brief that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; every planet, moon, gear and bookshelf is generated procedurally in the browser.
