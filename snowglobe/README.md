# Snow Globe

A voxel winter village under glass, in a single HTML file. Play it at https://play-grounds.github.io/games/snowglobe/

- The brief that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; the village, the snow and the music box are all generated in the browser.
