# Railway Model

A tabletop voxel model railway in a hobby room, in a single HTML file. Play it at https://play-grounds.github.io/games/railway/

- The brief that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; the terrain, track, town, trains and traffic are all generated procedurally in the browser.
