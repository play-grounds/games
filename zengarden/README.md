# Zen Garden

A voxel Japanese dry garden you rake yourself, in a single HTML file. Play it at https://play-grounds.github.io/games/zengarden/

- The brief that produced the scene is in [PROMPT.md](PROMPT.md).
- Built with [Three.js](https://threejs.org/) r128 from cdnjs; the garden, the gravel, the koi and the sounds are all generated in the browser.
